# 62. 不同路径

> 🔗 题目链接：[中文站](https://leetcode.cn/problems/unique-paths/) ｜ [国际站](https://leetcode.com/problems/unique-paths/)
>
> 🟡 中等 ｜ 标签：`动态规划` `数学`

## 📝 题目描述

一个机器人位于 `m × n` 网格的**左上角**（起点标记为 "Start"）。机器人每次只能**向下**或者**向右**移动一步，问它到达网格的**右下角**（终点标记为 "Finish"）总共有多少条不同的路径。

路径数只与网格的尺寸有关，与格子内容无关。

**示例 1：**

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向右 -> 向下
3. 向下 -> 向下 -> 向右
```

**提示：**

- `1 <= m, n <= 100`
- 题目数据保证答案小于或等于 `2 * 10^9`

## 💡 题解

### 解法一：二维动态规划

**思路**：设 `dp[i][j]` 为从起点 `(0, 0)` 走到格子 `(i, j)` 的路径数。由于机器人只能从**上方** `(i-1, j)` 或**左侧** `(i, j-1)` 进入当前格子，因此：

`dp[i][j] = dp[i-1][j] + dp[i][j-1]`

边界条件：第一行的格子只能一路向右到达，第一列只能一路向下到达，故全部初始化为 `1`。答案即 `dp[m-1][n-1]`。

```cpp
#include <vector>

class Solution {
public:
    int uniquePaths(int m, int n) {
        // dp[i][j]：从 (0,0) 走到 (i,j) 的路径数
        vector<vector<int>> dp(m, vector<int>(n, 1));  // 首行、首列均为 1
        for (int i = 1; i < m; ++i) {
            for (int j = 1; j < n; ++j) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};
```

- ⏱️ 时间复杂度：`O(mn)`
- 💾 空间复杂度：`O(mn)`

### 解法二：滚动数组优化

**思路**：计算第 `i` 行时只用到第 `i-1` 行的值和当前行左边的值，可以把二维压成一维：`dp[j]` 在更新前保存的正是上一行的 `dp[i-1][j]`，而 `dp[j-1]` 已经是本行的 `dp[i][j-1]`，于是一句 `dp[j] += dp[j-1]` 完成转移。注意内层循环必须**从左往右**扫。

```cpp
#include <vector>

class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);  // 首行：全为 1
        for (int i = 1; i < m; ++i) {
            for (int j = 1; j < n; ++j) {
                dp[j] += dp[j - 1];  // 上方 dp[i-1][j] + 左侧 dp[i][j-1]
            }
        }
        return dp[n - 1];
    }
};
```

- ⏱️ 时间复杂度：`O(mn)`
- 💾 空间复杂度：`O(n)`

### 解法三：组合数学（推荐）

**思路**：从左上角到右下角，无论怎么走，都恰好移动 `m + n - 2` 步，其中 `m - 1` 步向下、`n - 1` 步向右。一条路径就等价于在这 `m + n - 2` 个步位中选出哪些步向下——答案是组合数：

`C(m + n - 2, m - 1) = (m + n - 2)! / ((m - 1)! * (n - 1)!)`

直接算阶乘会立刻溢出，采用"**边乘边除**"：取 `k = min(m, n) - 1` 减少乘法次数，第 `i` 轮执行 `ans = ans * (N - k + i) / i`（`N = m + n - 2`）。每轮结束后 `ans` 恰为组合数 `C(N - k + i, i)`，因此除法总是整除；又因为各因子均不小于 1，中间结果单调不减、不会超过最终答案，用 `long long` 足够安全（题目保证答案 ≤ 2 × 10^9）。

```cpp
#include <algorithm>

class Solution {
public:
    int uniquePaths(int m, int n) {
        // 在 m+n-2 步中选出 min(m,n)-1 步向下，即 C(m+n-2, min(m,n)-1)
        int total = m + n - 2;
        int k = min(m, n) - 1;
        long long ans = 1;
        for (int i = 1; i <= k; ++i) {
            ans = ans * (total - k + i) / i;  // 每轮结果仍是组合数，保证整除
        }
        return (int)ans;
    }
};
```

- ⏱️ 时间复杂度：`O(min(m, n))`
- 💾 空间复杂度：`O(1)`

## ⚠️ 易错点

- 滚动数组内层循环必须**从左往右**：先更新 `dp[j-1]`，后面才能拿到"本行左侧"的值；反向扫描会把上一行的值当本行用。
- 组合数解法不能"先算完整分子再除分母"，中间乘积会迅速溢出；必须每轮乘一个除一个，且**乘法在前、除法在后**才保证整除。
- 累乘变量要用 `long long`：`int` 装不下 `ans * (total - k + i)` 这种中间乘积。
- 组合数是"`m + n - 2` 选 `m - 1`"，别误写成 `m + n - 1` 或 `m`——把总步数与格数搞混是最常见的笔误。
