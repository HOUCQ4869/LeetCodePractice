# 75. 颜色分类

> 🔗 题目链接：[中文站](https://leetcode.cn/problems/sort-colors/) ｜ [国际站](https://leetcode.com/problems/sort-colors/)
>
> 🟡 中等 ｜ 标签：`双指针` `排序`

## 📝 题目描述

给定一个包含红色、白色和蓝色（共 `n` 个元素）的数组 `nums`，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色的顺序排列。

用整数 `0`、`1`、`2` 分别表示红色、白色和蓝色。要求**不使用库内置的排序函数**，并且尝试设计仅使用常数空间的一趟扫描算法。

**示例 1：**

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

**示例 2：**

```
输入：nums = [2,0,1]
输出：[0,1,2]
```

**提示：**

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` 为 `0`、`1` 或 `2`

**进阶**：你能想出一个仅使用常数空间的一趟扫描算法吗？

## 💡 题解

**关键观察**：值只有 `0`、`1`、`2` 三种，且要求原地操作——这正是"荷兰国旗问题"，可以用双指针把数组一次性划分成 `000...111...222` 三个区段。

### 解法一：计数排序（两趟扫描）

**思路**：第一趟统计 `0`、`1`、`2` 各自出现的次数；第二趟按个数依次覆写数组——先写 `cnt[0]` 个 `0`，再写 `cnt[1]` 个 `1`，最后写 `cnt[2]` 个 `2`。由于取值范围极小，这比通用排序更快、更简单，但需要两趟扫描。

```cpp
#include <vector>

class Solution {
public:
    void sortColors(vector<int>& nums) {
        int cnt[3] = {0, 0, 0};
        for (int x : nums) {
            ++cnt[x];  // 统计每种颜色出现次数
        }
        int idx = 0;
        for (int v = 0; v < 3; ++v) {
            for (int k = 0; k < cnt[v]; ++k) {
                nums[idx++] = v;  // 按顺序覆写
            }
        }
    }
};
```

- ⏱️ 时间复杂度：`O(n)`
- 💾 空间复杂度：`O(1)`

### 解法二：三指针一趟扫描（推荐）

**思路**：维护三个区段——`[0, p0)` 全是 `0`，`(p2, n-1]` 全是 `2`，中间未处理。指针 `i` 从左向右扫描未确定区段：

- 遇到 `0`：与 `nums[p0]` 交换并让 `p0` 右移。由于 `i >= p0`，换到 `i` 处的只可能是 `1`（或 `i == p0` 时的 `0` 自身），无需重查，`i` 直接前进；
- 遇到 `2`：与 `nums[p2]` 交换并让 `p2` 左移。但换到 `i` 处的值来自右段、情况未知（可能是 `0`、`1` 甚至 `2`），所以 `i` **不能前进**，要用 `while` 继续处理；
- 遇到 `1`：本来就属于中段，直接前进。

循环条件为 `i <= p2`，扫到 `p2` 即说明中段只剩 `1`，排序完成。

```cpp
#include <utility>
#include <vector>

class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = (int)nums.size();
        int p0 = 0, p2 = n - 1;  // [0,p0) 全 0，(p2,n-1] 全 2
        for (int i = 0; i <= p2; ) {
            if (nums[i] == 0) {
                swap(nums[i], nums[p0]);
                ++p0;
                ++i;  // 换回来的一定是 1（或自身），可直接前进
            } else if (nums[i] == 2) {
                swap(nums[i], nums[p2]);
                --p2;
                // 换回来的值未知，i 不动，继续处理当前位置
            } else {
                ++i;  // nums[i] == 1，天然属于中段
            }
        }
    }
};
```

- ⏱️ 时间复杂度：`O(n)`（每个元素至多被交换常数次）
- 💾 空间复杂度：`O(1)`

## ⚠️ 易错点

- 遇 `2` 与右段交换后 `i` **不能自增**：换回来的可能是任意值，必须停在原地继续判断，否则 `[1,2,0]` 这类输入会出错。
- 循环上界是 `i <= p2` 而非 `i < n`：越过 `p2` 后是已就位的 `2` 区段，再处理会把排好的元素打乱。
- 遇 `0` 交换后可以直接 `++i`，这一步依赖"左段交换只会换回 `1`"的隐含不变量，若初始化或分支顺序写错，该结论可能失效。
- 若把对 `2` 的处理写成 `if` 而非保持 `i` 不动的结构，注意连续多个 `2` 会被一次性堆到右段，需要 `while` 语义（上面的 `for` 中 `i` 不自增即等价于 `while`）。
