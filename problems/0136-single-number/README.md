# 136. 只出现一次的数字

> 🔗 题目链接：[中文站](https://leetcode.cn/problems/single-number/) ｜ [国际站](https://leetcode.com/problems/single-number/)
>
> 🟢 简单 ｜ 标签：`位运算` `数组`

## 📝 题目描述

给定一个**非空**整数数组 `nums`，其中除了某个元素**只出现一次**以外，其余每个元素都**出现两次**。请找出那个只出现了一次的元素。

要求：不使用额外空间（即额外空间复杂度为 `O(1)`）的情况下实现线性时间算法。

**示例 1：**

```
输入：nums = [2,2,1]
输出：1
```

**示例 2：**

```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**

```
输入：nums = [1]
输出：1
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除某个元素只出现一次外，其余每个元素均出现两次

## 💡 题解

**关键性质**：异或运算 `^` 满足交换律、结合律，且 `x ^ x = 0`、`x ^ 0 = x`。因此把数组全部元素异或起来，成对出现的元素互相抵消为 `0`，最终只剩下出现一次的那个数。

### 解法一：哈希表

**思路**：用哈希集合遍历数组：元素不在集合中就插入，已存在就删除。成对元素一插一删恰好抵消，遍历结束后集合里剩下的唯一元素就是答案。思路直白，但需要 `O(n)` 额外空间。

```cpp
#include <unordered_set>
#include <vector>

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_set<int> seen;
        for (int x : nums) {
            if (seen.count(x)) {
                seen.erase(x);  // 第二次出现，成对抵消
            } else {
                seen.insert(x);  // 第一次出现
            }
        }
        return *seen.begin();  // 只剩出现一次的那个数
    }
};
```

- ⏱️ 时间复杂度：`O(n)`
- 💾 空间复杂度：`O(n)`

### 解法二：异或（推荐）

**思路**：利用异或的性质 `x ^ x = 0` 与 `x ^ 0 = x`，以及异或满足交换律和结合律。把所有元素从头异或到尾，出现两次的元素无论相隔多远都会两两配对抵消为 `0`，最后的结果就是只出现一次的那个元素。一遍循环、一个变量，无需任何额外数据结构。

```cpp
#include <vector>

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for (int x : nums) {
            ans ^= x;  // 成对元素抵消为 0，只剩出现一次者
        }
        return ans;
    }
};
```

- ⏱️ 时间复杂度：`O(n)`
- 💾 空间复杂度：`O(1)`

## ⚠️ 易错点

- 该异或解法**只适用于"其余元素恰好出现两次"** 的前提；若其余元素出现三次（如 137 题），异或无法直接套用。
- 不要用求和再减两倍的做法硬套：先求 `2 * sum(去重集合) - sum(数组)` 也可以，但需要哈希表去重，空间不为 `O(1)`。
- 异或结果与遍历顺序无关，不要试图"排序后找落单者"——排序本身已是 `O(n log n)`。
- 注意 `0` 是合法元素：`ans` 初始化为 `0` 恰好是异或的单位元，不影响结果。
