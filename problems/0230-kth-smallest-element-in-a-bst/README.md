# 230. 二叉搜索树中第 K 小的元素

> 🔗 题目链接：[中文站](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/) ｜ [国际站](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)
>
> 🟡 中等 ｜ 标签：`树` `中序遍历`

## 📝 题目描述

给定一棵二叉搜索树（BST）的根节点 `root` 和一个整数 `k`，请你返回树中**第 `k` 小**的节点值（`k` 从 `1` 开始计数）。

- BST 性质：左子树所有节点值 < 根节点值 < 右子树所有节点值，因此其中序遍历恰好得到升序序列，第 `k` 小的元素即中序序列的第 `k` 个；
- 题目保证 `1 <= k <= 树中节点数`，答案一定存在。

**示例 1：**

```
输入：root = [3,1,4,null,2], k = 1
输出：1
解释：中序遍历得到升序序列 [1,2,3,4]，第 1 小的元素是 1。
```

**示例 2：**

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
解释：中序遍历得到升序序列 [1,2,3,4,5,6]，第 3 小的元素是 3。
```

**提示：**

- 树中的节点数 `n` 满足 `1 <= n <= 10^4`
- `1 <= k <= n`
- `-10^4 <= Node.val <= 10^4`
- **进阶**：若二叉搜索树经常被修改（插入/删除操作），且你需要频繁查找第 `k` 小的值，你将如何优化算法？

## 💡 题解

### 解法一：递归中序遍历 + 计数

**思路**：中序遍历按升序访问节点。维护计数器 `k`（引用传递）与答案变量：每访问一个节点就把 `k` 减一，减到 `0` 时当前节点即为第 `k` 小。找到答案后让后续所有递归调用立即返回（通过 `k == 0` 判断），避免遍历剩余部分。

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        dfs(root, k);
        return ans_;
    }

private:
    int ans_ = 0;

    void dfs(TreeNode* node, int& k) {
        if (!node || k == 0) return;   // 空节点，或已经找到答案
        dfs(node->left, k);            // 先访问更小的左子树
        if (--k == 0) {                // 当前节点是第 k 小
            ans_ = node->val;
            return;
        }
        dfs(node->right, k);           // 再访问更大的右子树
    }
};
```

- ⏱️ 时间复杂度：`O(n)`（最坏情况下遍历全树）
- 💾 空间复杂度：`O(h)`（递归栈深度为树高）

### 解法二：迭代中序遍历（推荐）

**思路**：用显式栈做中序遍历，天然支持**提前终止**：先把左链压栈下降到最小节点，之后每弹出一个节点就计数一次，第 `k` 个弹出的节点就是答案，直接 `return`，不再触碰剩余部分。当 `k` 很小时几乎只走一条左链，代价仅 `O(h + k)`。这也指明了进阶问题的方向：若树会被频繁修改，可在每个节点上额外维护「以该节点为根的子树节点数」，查询时从根出发按左右子树规模选方向，单次查询 `O(h)`，插入/删除时同步更新计数即可。

```cpp
#include <stack>

class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        stack<TreeNode*> stk;
        TreeNode* cur = root;
        while (cur || !stk.empty()) {
            while (cur) {              // 一路向左压栈
                stk.push(cur);
                cur = cur->left;
            }
            cur = stk.top();           // 栈顶即当前未访问的最小节点
            stk.pop();
            if (--k == 0) {
                return cur->val;       // 第 k 个被访问的节点
            }
            cur = cur->right;          // 转向右子树
        }
        return -1;                     // 不会到达（题目保证 1 <= k <= n）
    }
};
```

- ⏱️ 时间复杂度：`O(h + k)`（先下降 `h` 层到最左节点，再依次访问 `k` 个节点）
- 💾 空间复杂度：`O(h)`

## ⚠️ 易错点

- 第 `k` 小对应**中序遍历**（左-根-右）的第 `k` 个节点，别误用前序或后序直接数第 `k` 个。
- 递归版的计数顺序必须「先递归左子树、再自减」：若先自减再进左子树，会把当前根错误地计入更小的排名。
- 找到答案后要及时剪枝返回（如 `k == 0` 判断），否则最坏仍遍历整棵树，丧失提前终止的意义。
- 进阶问题不能靠「每次查询都全树中序遍历」解决：树频繁插入/删除时，应维护每个节点的子树大小（或改用平衡树/有序统计结构），让单次查询降到 `O(h)`。
